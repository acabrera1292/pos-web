# POS Web (JavaScript + Node + SQLite)

This is a simple web‑based POS system with:

✅ Multi‑user login  
✅ Inventory CRUD  
✅ Sales / POS cart  
✅ Daily / Weekly / Monthly reports  
✅ Configurable low inventory threshold  
✅ SQLite backend (easy to move to MySQL)

---

## 🚀 How to Run

### Backend


cd backend
npm install
node server.js


### Frontend
Open in browser:


frontend/index.html
